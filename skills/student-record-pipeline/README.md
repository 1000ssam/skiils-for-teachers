# student-record-pipeline

**한 반 학생들의 활동지를 모아 교과세특 초안을 한꺼번에 만드는 스킬입니다.**

손으로 쓴 활동지를 스캔한 것, 사진으로 찍은 것, 구글폼이나 한글 파일로 받은 것 — 어느 쪽이든 받습니다.
받아서 학생별로 짝지어 주고, 선생님이 중요한 대목에 형광펜을 칠하면, 그 부분을 바탕으로 세특 문장을 만듭니다.

**완성본을 만들지는 않습니다.** 언제나 '초안'만 내놓고, 선생님이 읽고 확정한 것만 NEIS로 넘어갑니다.

> ⚠️ **2026학년도 기준입니다.** 학교생활기록부 기재요령은 해마다 바뀝니다.
> 새 학년도에는 근거 파일(`references/giwan-*-grounding.md`)과 글자 수 규칙, 금지어 목록을 손봐 주세요.

---

## 이 스킬의 포인트

- **무엇을 쓸지는 선생님이 고릅니다.** AI가 학생 글을 훑어 알아서 고르는 게 아니라, 선생님이 화면에서
  형광펜으로 칠한 부분만 재료가 됩니다. 없는 이야기를 지어내는 건 나중에 읽어봐서 걸러내기 어렵습니다 —
  문장이 그럴듯하게 나오기 때문입니다. 그래서 나중에 걸러내는 대신 **처음부터 재료를 선생님이 정하게** 했습니다.
- **규칙은 공식 문서에서 가져왔습니다.** 글자 수, 금지 표현, 문체, AI 관련 조항은 **2026 기재요령**에서,
  성취수준을 가늠하는 표현 사전은 **2022 개정 교육과정 별책과 KICE 세특 예시집**에서 뽑았습니다.
  어디서 왔는지는 [`PROVENANCE.md`](PROVENANCE.md)에 다 적어 뒀습니다.
- **엉뚱한 학생 세특이 나오는 일이 없게 합니다.** 명렬표, 파일 순서, 활동지에 적힌 이름 — 이 셋을 맞춰 보고
  셋 다 맞을 때만 자동으로 넘어갑니다. 하나라도 어긋나면 선생님께 확인을 받습니다.
- **안 쓴 걸 썼다고 하지 않습니다.** 흐리게 찍혀 글자가 깨진 곳은 문맥으로 되살리되, 학생이 하지 않은 걸
  채워 넣지는 않습니다. 도저히 못 읽는 곳은 `[판독불가]`로 표시하고 넘어갑니다.
- **기계가 잴 것과 선생님이 볼 것을 나눴습니다.** 글자 수, 금지 표현, 점수 언급 같은 건 기계가 자동으로 잡습니다.
  하지만 "이 근거가 이 문장을 정말 뒷받침하나" 같은 건 문맥을 알아야 하므로 판단하지 않고 선생님께 넘깁니다.

## 설치 (이 스킬만)

아래 명령어는 **`student-record-pipeline` 하나만** 설치합니다. 다른 스킬은 건드리지 않습니다.

### 방법 1. 명령어 한 줄 (추천)

- **Windows** — PowerShell에 붙여넣고 Enter:
  ```powershell
  irm https://raw.githubusercontent.com/1000ssam/skills-for-teachers/main/skills/student-record-pipeline/install.ps1 | iex
  ```
  > **PowerShell 여는 방법:** `Win + R` → `powershell` 입력 → Enter

- **macOS / Linux** — 터미널에 붙여넣고 Enter:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/1000ssam/skills-for-teachers/main/skills/student-record-pipeline/install.sh | bash
  ```
  > **터미널 여는 방법 (Mac):** `Cmd + Space` → `터미널` 입력 → Enter

설치 후 **Claude Code를 재시작**하면 됩니다.

### 방법 2. 파일 직접 다운로드

1. [메인 리포](https://github.com/1000ssam/skills-for-teachers)에서 초록색 **`<> Code` → `Download ZIP`**.
   > ⚠️ 이 페이지(개별 스킬 폴더)가 아닌 **메인 리포 첫 화면**에서 받아야 합니다.
2. 압축을 풀고 `skills/student-record-pipeline` 폴더 **하나만** 아래 경로에 복사:
   - Windows: `C:\Users\{내 사용자 이름}\.claude\skills\`
   - macOS/Linux: `~/.claude/skills/`
   > `.claude` 폴더가 안 보이면: 파일 탐색기 → **보기** → **숨긴 항목** 체크
3. **Claude Code 재시작.**

### 방법 3. 리포를 이미 내려받았다면

```bash
# macOS / Linux
mkdir -p ~/.claude/skills
cp -rf skills/student-record-pipeline ~/.claude/skills/
```

```powershell
# Windows (PowerShell) — 내려받은 리포 폴더에서 실행
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse -Force .\skills\student-record-pipeline "$env:USERPROFILE\.claude\skills\"
```

> 다른 스킬까지 전부 설치하려면 [메인 리포 README](https://github.com/1000ssam/skills-for-teachers#전체-설치-모든-스킬-한-번에)의 전체 설치 명령어를 쓰세요.

## 쓰는 법

Claude Code에서 이렇게 말하면 됩니다:

| 이렇게 말하면 | 이렇게 움직입니다 |
|------|------|
| `"반 전체 세특 초안 만들어줘"` | **먼저 이것저것 물어봅니다.** 대답을 다 받은 다음에 시작합니다 |
| `"수행평가 산출물로 세특 써줘"` | 활동지가 스캔인지 사진인지 파일인지 묻고, 그에 맞게 읽어들입니다 |
| `"활동지 스캔해서 세특 만들어줘"` | 사진 → 글자 → 학생별 짝짓기 → 형광펜 → 문장 만들기 → 점검 |

**바로 쓰기 시작하지 않습니다.** 어떤 과제였는지, 채점 기준은 무엇인지, 무엇을 보려던 활동인지,
분량은 얼마인지, 명렬표는 어디 있는지, 활동지가 몇 칸짜리인지를 하나씩 물어봅니다.
그 대답들을 모아 '이번 과제 설명서'를 한 장 만들고, 그 설명서가 이후 모든 단계를 움직입니다.
과목이 바뀌면 이 설명서만 새로 쓰면 됩니다.

---

## 어떤 순서로 움직이나

| 순서 | 하는 일 |
|---|---|
| **1. 물어보기** | 과제·채점 기준·분량·문체·명렬표·활동지 칸 구성을 하나씩 확인합니다 |
| **2. 글 읽어들이기** | 활동지에서 학생이 쓴 글을 글자로 뽑아냅니다 (아래 "어떤 형태든 받습니다") |
| **3. 학생별로 짝짓기** | 명렬표와 맞춰 봅니다. 애매하면 넘기지 않고 선생님께 물어봅니다 |
| **4. 깨진 글자 바로잡기** | 흐리게 읽힌 글자만 되살립니다. 내용을 보태지는 않습니다 |
| **5. 형광펜 칠하고 문장 만들기** | 선생님이 화면에서 중요한 대목을 칠하면, 그 부분으로 초안을 씁니다 |
| **6. 점검하고 내놓기** | 기계가 글자 수·금지 표현 등을 훑고, 선생님이 문장과 근거를 나란히 놓고 판정합니다 |
| **7. NEIS에 넣기** | (선택) NEIS에서 내려받은 엑셀이 있으면 확정본을 그 파일에 되돌려 넣습니다 |

각 단계에서 지키는 규칙은 [`SKILL.md`](SKILL.md)에 자세히 적혀 있습니다.

### 어떤 형태든 받습니다

- **① 이미 글자로 된 것** (구글폼 응답, 한글·워드 파일, 타이핑) → 그대로 씁니다.
- **② 스캔이나 사진 + OCR 프로그램이 있는 경우** → 쓰시던 OCR로 글자를 뽑으면 됩니다. 특정 회사 제품을 가리지 않습니다.
- **③ OCR이 없는 경우** → AI가 사진을 직접 보고 옮겨 적습니다. 이때는 **복사기처럼** 옮기게 시킵니다 —
  맞춤법을 고치거나 반쯤 쓴 문장을 완성하지 않고, 못 읽는 글자는 `[판독불가]`로 둡니다.

셋 다 그 뒤로는 똑같은 길로 갑니다.

## 형광펜 화면 (5단계에서 실제로 하는 일)

`references/marking-tool/` 폴더가 그 화면입니다. 작업 폴더로 복사한 뒤 실행하면 브라우저에서 씁니다.
인터넷으로 나가는 것은 없고, 선생님 컴퓨터 안에서만 돕니다.

```bash
cp -r ~/.claude/skills/student-record-pipeline/references/marking-tool/* <작업폴더>/tool/
cd <작업폴더> && node tool/server.mjs      # 브라우저에서 http://localhost:7333/
```

**왼쪽에서 학생을 고르고, 화면은 두 개입니다.**

- **형광펜 화면** — 세 칸으로 나뉘어 있습니다. 왼쪽 `원문`에서 중요한 대목을 마우스로 드래그하면 바로 칠해지고,
  가운데 `주석`에 왜 그 대목을 골랐는지 적고, 오른쪽 `총평`에 어떤 역량이 보였는지·어느 정도 도달했는지(상/중/하)를
  넣습니다. 위아래로 왔다 갔다 할 일이 없습니다.
- **검수 화면** — 나온 초안 문장과, 글자 수 막대와, **그 문장이 어느 형광펜에서 나왔는지**를 나란히 보여줍니다.
  여기서 **[확정] / [다시] / [보류]**를 누릅니다.

지금 어디까지 됐는지는 왼쪽 목록의 점 색으로 봅니다: 아직 안 함 → 만드는 중 → **초안 나옴(파랑 = 읽어야 할 것)**
→ **확정(초록 = 끝난 것)**, 그리고 보류. 키보드로도 됩니다 — `J`/`K` 학생 이동, `1`/`2`/`3` 도달 수준,
검수 화면에서 `A`(확정)·`R`(다시)·`H`(보류).

- **안 칠하고 그냥 맡겨도 됩니다.** 형광펜을 하나도 안 칠하면 AI가 학생 글에서 알아서 고릅니다(화면에는 '위임'으로 표시).
  대신 선생님이 검수에서 볼 게 많아지니, 화면이 눈에 띄게 표시해 줍니다. 자꾸 마음에 안 들면 다시 만들게 하기보다
  **직접 칠하시는 편이 빠릅니다.**
- **확정한 것만 NEIS로 갑니다.** 생기부는 법적 문서이고 최종 책임이 선생님께 있으니,
  "아직 안 읽음"과 "읽어봤고 괜찮음"을 반드시 구분합니다.
- **칠한 걸 고치면 확정이 저절로 풀립니다.** 확정해 놓고 재료만 바뀌어 있는 상태를 막기 위해서입니다.
- 도구를 손보셨다면 검사를 한 번 돌려 보세요: `node tool/test_mark_ui.mjs && python3 tool/test_pending.py` (65가지 검사)

## 미리 준비할 것

- **Python 3** — 짝짓기·점검·글자 수 계산에 씁니다. 추가로 설치할 것은 없습니다.
- **Node.js** — 형광펜 화면을 띄우는 데 씁니다. 이것도 추가 설치할 것은 없습니다.
- **`openpyxl`** — 7단계(NEIS에 넣기)를 쓸 때만 필요합니다: `pip install openpyxl`. 안 쓰면 필요 없습니다.
- **명렬표** — 되도록 NEIS에서 `과목별 세부능력 및 특기사항`을 엑셀로 내려받아 주세요.
  명렬표 겸 최종 제출 파일이 되어서, 완성된 초안을 그 파일 하나에 그대로 되돌려 넣을 수 있습니다.

## 절대 어기지 않는 6가지

1. 학생을 짝지을 때 어림짐작하지 않는다. 확실하지 않으면 선생님께 묻는다.
2. 깨진 글자를 되살리기만 한다. 없는 내용을 보태지 않는다. 못 읽으면 `[판독불가]`.
3. 교육과정 성취기준은 뒤에서 근거로만 쓰고, 문장은 선생님이 보려던 것을 중심으로 쓴다.
4. 분량은 상한이지 채워야 할 하한이 아니다. 채우려고 말을 늘리지 않는다.
5. 점수·등급·석차를 문장에 쓰지 않는다.
6. 결과물은 언제나 '초안'이다. **NEIS에 넣기 전 선생님 확인을 반드시 거친다.**

2026 기재요령은 AI가 만든 글을 그대로 생기부에 넣는 것은 금지하지만, 문장을 다듬는 등 **보조 수단**으로 쓰고
넣기 전에 사실과 다른 곳이 없는지 확인하면 괜찮다고 봅니다. 이 스킬은 **그 확인을 반드시 거치게 만드는 도구**입니다.

## 개인정보

**스킬 폴더에는 학생 정보를 두지 않습니다.** 채워 넣은 과제 설명서, 명렬표, 학생이 쓴 글, 만들어진 세특 초안은
모두 개인정보이므로 스킬 폴더 바깥의 작업 폴더에 두고, 다른 곳에 올리거나 공유하지 않습니다.
형광펜 화면이 읽고 쓰는 `out/` 폴더도 마찬가지입니다.

## 폴더 구성

```
student-record-pipeline/
├── SKILL.md                          ← Claude Code가 따르는 실제 지침 (핵심)
├── README.md                         ← 이 문서
├── PROVENANCE.md                     ← 규칙이 어느 공식 문서에서 왔는지 정리
├── DESIGN-DECISIONS.md               ← 왜 이렇게 만들었는지, 한계는 무엇인지
├── install.ps1 / install.sh          ← 이 스킬만 설치하는 스크립트 (위 "설치")
└── references/
    ├── eval-context-spec.template.md    ← 과제 설명서 빈 양식
    ├── render-contract.template.md      ← 문장 작성 지침 양식 (예시 문장은 선생님이 채움)
    ├── marking-mode.md                  ← 형광펜을 칠했을 때·안 칠했을 때의 규칙
    ├── giwan-2026-grounding.md          ← 2026 기재요령에서 뽑은 근거 (쪽수 표시)
    ├── neis-byte-rule.md                ← NEIS 글자 수 규칙
    ├── forbidden-terms.txt              ← 쓰면 안 되는 표현 목록
    ├── recommended-structure.txt        ← 도달 수준을 가늠하는 표현 사전
    ├── achievement-standards-2022.csv   ← 2022 개정 성취기준 (전 교과)
    ├── standards.py                     ← 성취기준 찾아보기
    ├── neis_roster.py                   ← NEIS 엑셀에서 명렬표 뽑기
    ├── map_pages.py                     ← 활동지를 학생별로 짝짓기
    ├── mapping-config.example.json      ← 짝짓기 설정 예시 (활동지 모양을 적는 곳)
    ├── draft-rules.example.json         ← 분량·금지어 설정 예시
    ├── repeat-whitelist.example.txt     ← 같은 말 반복 검사에서 빼줄 낱말 예시
    ├── verify.py                        ← 글자 수·금지 표현 등 자동 점검
    ├── ledger_verify.py                 ← 문장의 근거가 학생 글에 실제로 있는지 대조
    ├── verify_anchors.py                ← 인명·지명·숫자가 학생 글에서 나온 것인지 확인
    ├── make_review_table.py             ← 문장과 근거를 나란히 놓은 검수표 만들기
    ├── neis_bytes.py                    ← NEIS 글자 수 계산
    ├── sentence_metrics.py              ← 문장이 너무 길지 않은지 표시
    ├── neis_writeback.py                ← 확정본을 NEIS 엑셀에 되돌려 넣기
    └── marking-tool/                    ← 형광펜 화면 (브라우저 + 검사 65가지)
```

실제로 움직이는 지침은 `SKILL.md` 하나입니다. 나머지는 근거 자료와 보조 도구입니다.
